CNF Converter PWA

1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html -> Open with Live Server.
4. Chrome opens http://127.0.0.1:5500/...
5. Enter grammar and click Convert to CNF.
6. At the final result, click Install App.
7. Confirm Install in Chrome.

Do NOT double-click index.html for PWA installation; use localhost or HTTPS.
