Problem Statement

Understanding the purpose of the CNF converter

Chomsky Normal Form Converter

Build a production system that transforms a simplified Context-Free Grammar (CFG) into Chomsky Normal Form. The final grammar contains productions in the form A → BC or A → a.

Core Concepts

Important concepts used during conversion

📘

CFG

A formal grammar containing variables, terminals, productions and a start symbol.

ε

Epsilon Production

A production that generates an empty string. Example: A → ε

🔗

Unit Production

A production where one variable produces another variable.

✓

CNF Validation

Checks whether productions follow A → BC or A → a.

CNF Rules

Valid production structures

A → BC

Variable produces two variables

A → a

Variable produces one terminal
